    Steam Review Triage & Response Agent

    About This Demo

    Each curated case in the sidebar is a real agent run reconstructed from persisted audit data. Click one to watch the full loop: coordinator → investigator → responder → critic → human gate.

    • Step through events one at a time with Next step / Previous.
    • Or play remaining at normal pace.
    • Each case has interviewer notes with the story.
    • Click any chunk id in Cited evidence to expand its patch-note text.

    Key Engineering Decisions

    • Coordinator is plain Python, not an LLM — deterministic routing, no token cost per hop.
    • Tiered model assignments — Haiku for narrow tasks (classifier, tone, critic); Sonnet for reasoning (investigator, responder).
    • Hybrid RAG — BM25 + vector + HyDE → RRF fusion → Gemma rerank → tool-use loop with up to 4 primary query reformulations + 1 secondary-aspect probe.
    • Evals are first-class — action correctness, retrieval recall, LLM judges, snapshot diffs.

    Memory Architecture

    • AgentState (working) — per-run TypedDict passed between nodes; checkpointed to SQLite so the graph can pause at the human gate and resume.
    • Audit log (episodic) — every completed run persisted with full state.
    • Cluster notes (institutional) — per-category memory (known issues, response history, human feedback) with 90-day TTL.
    • Patch vector store (ChromaDB) (semantic) — persistent index of every patch-note chunk, embedded with bge-base-en-v1.5.

    Pre-Agent Pipeline

    Pre-agent pipeline — data prep that runs before the LangGraph: fetch, dedupe, classify (category + tone + secondary aspects), build per-category clusters.

    Agent Graph

    Main path — forward flow + revision loop (critic back to coordinator on drafting or evidence reject). Action-freeze — coordinator intercepts action-only reject and routes directly to the gate, skipping another revision cycle. Memory-fed nodes — investigator reads active cluster_notes; responder reads approved drafts from audit_log as few-shot examples.
